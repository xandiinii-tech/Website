Privacy Policy

x andini · last updated 26 November 2026

Who this is about

This policy covers the website www.xandini.de and x andini poster, a private tool that the DJ x andini uses to publish short clips of his own DJ sets to his own social media accounts (TikTok, Instagram and YouTube).

The website

The website has no user accounts, no contact forms that store data and no advertising or tracking cookies. It is hosted on GitHub Pages and delivered through Cloudflare. These providers technically process connection data (such as IP address, browser type and time of access) to deliver the pages and protect them from abuse. Embedded players (for example SoundCloud or YouTube) are provided by those services and are subject to their own privacy policies.

x andini poster (TikTok, Instagram, YouTube)

  • The tool is used only by x andini and connects only to x andini's own accounts.
  • It uses the official APIs (TikTok Login Kit and Content Posting API, Instagram API, YouTube Data API) to upload videos that x andini created, together with captions he wrote.
  • It stores the access tokens for these accounts locally on x andini's own computer. They are never sold, shared or sent anywhere except to the platform they belong to.
  • From TikTok it uses only basic account information (display name, account ID) to confirm that it is connected to the right account, and the permission to upload videos.
  • It does not collect, store or process any data about other TikTok, Instagram or YouTube users.

Deleting access

Access can be revoked at any time in the account settings of each platform (for TikTok: Settings and privacy → Security → Manage app permissions). Revoking access makes the stored tokens useless; x andini then deletes them.
